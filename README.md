# NumPy-Numerical-Analysis-Projects
This is a collection of hands-on NumPy exercises focused on applying numerical computing to real-world scenarios.


## Overview

The projects cover business analytics, education analytics, engineering/scientific computing, and food production analysis. Each exercise demonstrates how NumPy can be used to work with numerical data, perform calculations efficiently, and interpret results in a practical context.


## Projects Included

**1. Business Analytics — Sales Performance Calculator**

This exercise analyzes one week of daily sales data for a retail business.

**Key tasks:**

- Created and inspected a NumPy array
- Calculated total weekly sales using np.sum()
- Calculated average daily sales using np.mean()
- Applied a hypothetical 10% sales increase
- Used element-wise subtraction to calculate additional revenue
- Interpreted the results from a business perspective

**Key result:**

The business recorded ₦1,150,000 in weekly sales, with an average daily sales figure of approximately ₦164,285.71.


**2. Education Analytics — Student Performance Analysis**

This exercise examines the performance of a group of students using their assessment scores.

**Key tasks:**

- Created and inspected a NumPy array
- Calculated the mean score
- Calculated each student's deviation from the mean
- Identified positive and negative deviations
- Squared the deviations
- Calculated the sum of squared deviations
- Connected the calculations to the concept of standard deviation

**Key result:**

The students had a mean score of 79.5. The deviations helped demonstrate how individual scores can differ from the group average and why looking beyond the mean provides more information about student performance.


**3. Engineering & Scientific Computing — Trigonometric Series**

This exercise explores numerical sequences and trigonometric calculations using NumPy.

**Key tasks:**

- Converted an angle from degrees to radians
- Used np.radians()
- Calculated a sine value using np.sin()
- Created numerical sequences with np.arange()
- Performed element-wise division
- Used np.sum() to calculate a series result
- Compared results using increasing numbers of terms
- Explored the concept of convergence

The experiment also provided an opportunity to distinguish between a series that approaches a limiting value and one whose result continues to increase as more terms are added.


**4. Bonus Project — Food Production Performance Analysis**

For the bonus challenge, I created a mini numerical experiment based on a simulated food production scenario.

The project analyzes the number of food packages produced over seven days and estimates the effect of a hypothetical 10% increase in production.

**Key tasks:**

- Created a numerical dataset using np.array()
- Calculated total production using np.sum()
- Calculated average production using np.mean()
- Applied a 10% increase using element-wise multiplication
- Calculated additional production using element-wise subtraction
- Compared original and adjusted production levels
- Interpreted the results in a food production context

**Key result:**

The simulated production dataset recorded 9,250 packages for the week, with an average daily production of approximately 1,321 packages. A hypothetical 10% increase would raise weekly production to 10,175 packages, representing an additional 925 packages.
